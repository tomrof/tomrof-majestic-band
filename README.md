# Tomrof and the Majestic Band

Application statique installable (PWA). Ouvrir index.html depuis un serveur HTTP local ou publier les fichiers via GitHub Pages (branche main, dossier racine). Aucun build ni dépendance.

Les textes sont dans content.js. Après une modification, changer la version du cache dans sw.js et publier tous les fichiers. Le logo original est conservé sans modification. Les photos et biographies sont proposées aux musiciens pour validation. Les vidéos YouTube nécessitent Internet. Boutique et précommandes : à venir.
